## 📌 Sobre o Projeto
Este projeto gera páginas de exercícios de coordenação motora para crianças. Com Python e a biblioteca Pillow, crio caminhos visuais que conectam um ponto inicial até uma letra ou forma-alvo — prontos para imprimir e usar em casa, na escola ou na terapia.

### ✅ O que já funciona:
- [x] Estrutura da página com título
- [x] Ponto inicial e caminhos visuais
- [x] Área de chegada com a letra alvo
- [x] Linha de treino da letra
- [x] Exportação de imagem pronta para impressão

### 🔄 O que vem a seguir:
- [ ] Labirintos com caminhos mais naturais e curvos
- [ ] Ilustrações: capivara, folhas, flores e detalhes visuais
- [ ] Área para preencher Nome e Data
- [ ] Letras pontilhadas para treino de escrita
- [ ] Novas letras e temas
